# Visual Study-Guide Standard — LOCKED

**Status:** LOCKED after Week 8 hybrid pilot approval  
**Applies to:** MBB201 Part II weekly study guides, Weeks 8–12

## 1. Governing principle

The weekly lecture remains the authority for **scope**. Visual enrichment must clarify the material already taught; it must not expand the examinable scope.

Alberts provides detailed mechanistic support. Tutorials provide course-specific explanatory and problem-solving visual logic.

## 2. Locked hybrid visual grammar

Each weekly study guide should combine three visual layers.

### A. Orientation / summary visuals

Original web-native diagrams that help students organize the week:

- big-picture roadmap;
- pathway or process overview;
- comparison tables/cards;
- accounting or stoichiometry summaries;
- exam-oriented summary graphics.

### B. Course-source visual adaptations

Selected lecture/tutorial graphics or teaching metaphors are adapted into clean web-native SVGs when they are central to how the course presents a concept.

These must:

- preserve the teaching logic of the source;
- be marked with the **COURSE VISUAL** label;
- include a source-aware caption identifying the lecture/tutorial location;
- appear next to the concept they explain, not in a detached gallery.

### C. Textbook-grounded conceptual redraws

Textbook concepts may be redrawn into original explanatory schematics.

Do not reproduce textbook pages or textbook figures verbatim on the public GitHub site unless permission and reuse terms clearly support doing so.

## 3. Placement rule

A visual must have a pedagogical job.

Preferred sequence:

**concept introduction → explanatory prose → visual → interpretation / exam implication**

Do not add decorative images merely to make a page look fuller.

## 4. Density

The approved Week 8 pilot established that approximately **7–9 meaningful visuals per weekly guide** is appropriate for these materials.

The exact number depends on the visual complexity of the topic.

## 5. Visual style

- SVG preferred for diagrams and pathway graphics.
- Responsive width for desktop and mobile.
- Consistent rounded containers, restrained color, and readable labels.
- Every visual requires meaningful alt text.
- Every visual requires a concise caption.
- Course-derived adaptations use the existing `course-source-visual` styling.

## 6. Source hierarchy

1. Weekly lecture presentation — scope and course emphasis.
2. Weekly learning objectives — required coverage.
3. Tutorials — course-specific explanatory and application logic.
4. Alberts textbook chapter(s) — detailed mechanistic explanation.
5. No outside scholarship unless explicitly requested.
